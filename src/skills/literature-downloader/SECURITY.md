# 安全与隐私政策

## 支持范围

本项目关注：

- 个人隐私泄露
- API key、token、Cookie、账号信息泄露
- 误提交下载论文、日志或本机路径
- 可能诱导绕过付费墙或访问控制的代码
- 可能违反出版社、数据库或平台条款的行为

## 不支持的行为

请不要提交或请求：

- 盗版论文下载
- 付费墙绕过
- 账号共享
- Cookie/会话复用
- DRM 破解
- 对出版社或数据库的高频抓取、规避限流

## 报告问题

如果你发现安全或隐私问题，请在 GitHub 上提交 issue，并尽量避免公开贴出真实 token、账号、Cookie、论文 PDF 或个人路径。

如果必须说明敏感细节，请先做脱敏处理，例如：

```text
<本机用户目录>\...
<凭据已脱敏>
```

## 维护者处理原则

- 先确认是否涉及隐私、凭据、版权或访问控制风险
- 必要时重写 Git 历史移除敏感内容
- 修复后补充 `.gitignore`、文档或脚本防护
- 对版权和访问控制风险采取保守策略
