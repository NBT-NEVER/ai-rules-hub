# Formula Character Expression Rules

本文件维护“公式字符如何表示/表达”的长期规则，覆盖对话展示、Word 格式文件、PPT 格式文件，以及与代码位于同一文件夹的 `README.md`。

## 1. 对话中出现的公式字符

适用场景：在对话里介绍、说明、解释公式。

基本要求：

- 必须连续给出两个版本：先给“完全渲染版”，再给“LaTeX 版”。
- 渲染版必须完全可读，不出现裸露 LaTeX 源码。
- 渲染版解释变量时，直接使用数学字符，例如 `γ`，不要写成 `\gamma`。
- LaTeX 版只在这里判断采用 Word 格式还是 PPT 格式，具体格式要求见第 2 部分。

选择逻辑：

- 如果用户提到 Word、docx、实验报告、论文、论文原理详解、论文公式解读、正式文档、写入文件、正文等，优先使用 Word 格式文件 LaTeX 版。
- 如果用户提到 PPT、PowerPoint、幻灯片、答辩汇报、演示文稿、复制到 PPT、课件等，使用 PPT 格式文件 LaTeX 版。
- 如果只说“给我公式解释”“在对话里展示”“讲一下这个公式”，但没有说明后续写入哪里，优先使用 PPT 格式文件 LaTeX 版。

## 2. LaTeX 版

适用场景：对话中公式后附带的 LaTeX 版，以及写入文档时使用，包括实验报告、论文、论文原理详解、论文公式解读等。

### 2a. Word 格式文件 LaTeX 版

格式要求：

- 公式和变量统一使用 `$...$` 包裹。
- 独立公式单独成行书写。
- 公式后新启一行写 `其中：`。
- 变量解释从 `其中：` 下一行开始逐项书写。
- 每个变量解释统一写成 `$变量LaTeX$：变量解释。`
- 中文解释文字不需要放进 `$...$`，只有公式字符、变量、上下标、希腊字母、分位数表达等数学部分需要放进 `$...$`。
- 适用于 Word、docx、实验报告、论文正文、论文原理详解、论文公式解读文件。

示例：

```text
$E_{ws} \ge \phi^{-1}_{w0}(1-\alpha)$

其中：
$E_{ws}$：AGV $w$ 到达节点 $\nu_s$ 时的能量下界。
$\phi^{-1}_{w0}(1-\alpha)$：AGV $w$ 当前初始能量随机变量的 $1-\alpha$ 分位数。
$\nu_s=I_w$：当前节点是 AGV $w$ 的初始节点。
$I_w$：AGV $w$ 的初始节点。
```

### 2b. PPT 格式文件 LaTeX 版

格式要求：

- 公式本身使用 `\(` 与 `\)` 包裹。
- 公式后新启一行写 `其中：`。
- 变量解释部分整体使用一组 `\(` 与 `\)` 包住。
- 不要把每个变量单独写成 `\(E_{ws}\)`、`\(w\)`、`\(\nu_s\)` 这种零散形式。
- 在整段 `\(...\)` 内，变量、上下标、希腊字母、分位数表达等数学字符使用 LaTeX 写法。
- 中文说明直接跟在变量后面，和 LaTeX 字符混排在同一个 `\(...\)` 内。
- 适用于 PPT、答辩汇报、课件、幻灯片、演示文稿。
- 无法判断目标格式时，优先使用这一种。

示例：

```text
\(E_{ws} \ge \phi^{-1}_{w0}(1-\alpha)\)

其中：
\(E_{ws}：AGV w 到达节点 \nu_s 时的能量下界。
\phi^{-1}_{w0}(1-\alpha)：AGV w 当前初始能量随机变量的 1-\alpha 分位数。
\nu_s=I_w：当前节点是 AGV w 的初始节点。
I_w：AGVw 的初始节点。\)
```

## 3. README.md 中的公式字符

适用场景：与代码位于同一文件夹的 `README.md`。

保持 `code-project-rules` 原规则不动：

- 使用 GitHub 可直接渲染的 LaTeX 格式。
- 行内公式使用 `$...$`。
- 独立成行公式使用 `$$...$$`。
- 不使用实验报告正文那种“先写渲染公式、下一行再重复 LaTeX 源码”的双行格式。
- 公式后仍写 `其中：`，并逐项解释公式变量。
- 变量解释统一使用 LaTeX 形式，例如 `$k_1$：变量解释。`
- 变量解释必须覆盖当前公式或公式组中的全部关键符号。
