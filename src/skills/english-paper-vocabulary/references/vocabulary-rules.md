# English Paper Vocabulary Rules

## 可参考的其余 skill

- `pdf:pdf`：用于读取、检查、渲染 PDF，提取页面文本和标注对象；当需要核对 PDF 注释、页码、原文句子或视觉位置时优先参考。
- `spreadsheets:Spreadsheets`：用于创建、编辑、验证 `.csv`、`.xlsx` 表格；当输出 Excel 并需要列宽、行高、冻结窗格、边框、筛选和视觉检查时优先参考。
- `chinese-encoding-guard`：用于中文释义、中文表头、中文说明、CSV 写入和中间文件处理，防止中文乱码。
- `literature-downloader`：仅在需要合法获取论文全文、核对 DOI、整理 Zotero/BibTeX 信息时参考；本 skill 不负责文献检索或下载。
- `recall-thinking`：当处理高价值 PDF、已有手工标注或批量输出前需要复用稳定经验时参考。

## 执行提示

只提取 Zotero PDF 中灰色下划线单个英文单词标注。不要总结其它颜色、其它标注类型、同色整句、术语短语或多词表达。输出文件名使用论文名，默认输出 `.csv`；用户要求排版时输出 `.xlsx`。CSV 内容严格为五列：单词、释义、音标、论文内例句、页码。

提取时应按 PDF 页码和页面内阅读顺序排序。若同一单词在多处被标注，默认保留第一次出现；若不同上下文含义明显不同，可保留多行并在释义中体现语境差异。论文内例句必须来自论文原文，应尽量取包含该词的完整句子；若 PDF 文本抽取导致断行或连字符断词，应在不改变原意的前提下恢复为可读句子，并优先用页面文本核对。

释义必须为中文，保留词性，不可只写一个笼统中文词。音标使用标准音标，优先使用英式或主流词典音标，保持全表风格一致。无法可靠确认音标时，应标注为待核对或向用户说明，不要编造。

CSV 文件不保存样式；若输出 Excel，按用户规则设置标题、表头、正文字号、列宽、统一数据行行高、自动换行、对齐、边框、冻结和筛选。数据行从第 3 行开始必须统一行高，不要因为内容长短自动改变每一行行高。

## 用户原始规则

我现在需要总结论文中的英文单词，释义，和论文中出现的例句。你会获得已经标记出来需要总结的论文带标注的pdf，需要你把我标出来的单词按照我的要求总结到scv表格中，并放在指定位置。要求如下：
1.论文是用zetero标注的，有其余的不同颜色的标注，以及相同颜色相同类型标注的句子，我都不需要，你仅查找并总结“使用灰色“、”下划线标注”的“单个单词”。灰色下划线在 PDF 里记录为 /Underline，颜色是 [0.66666667, 0.66666667, 0.66666667]，PDF 里灰色下划线标注很多是单词，但也混有少量术语短语和整句标注，这种非单词的术语短语和整句标注不需要总结。
2.读取论文名，并且把表格命名为与论文名同名的.csv
3.根据我标记的论文单词生成词汇总结表，表格采用 A-E 五列结构：A列为“单词”，B列为“释义”，C列为“音标”，D列为“论文内例句”，E列为“页码”。
4.词汇总结表第1行写论文标题，建议合并 A1:E1；第2行为表头；第3行开始填写词汇内容。单词按论文中出现顺序整理，释义使用中文并保留词性，不可省略释义，完全覆盖pdf中标注的释义；音标填写标准音标；论文内例句必须摘自论文原文，不要编造或改写；页码填写例句所在页。
5.若输出 CSV，只保留五列内容；若输出 Excel，则标题字号设为 16-18，表头字号设为 12-14，正文字号设为 11-12，字体可用“等线”或“Calibri”。列宽建议：A列 18-22，B列 40-48，C列 20-28，D列 80-100，E列 8-12。标题行和表头行可单独设置高度，从第3行开始所有词汇数据行必须使用统一行高，建议 70-85，不要根据内容自动改变行高；B、C、D列开启自动换行，A列和E列居中，B列左对齐，D列左对齐。表头居中加粗，数据区使用浅灰细边框，冻结前两行，并给表头开启筛选。
