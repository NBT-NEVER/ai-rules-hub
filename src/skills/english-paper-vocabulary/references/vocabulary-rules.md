# English Paper Vocabulary Rules

## 规则

我现在需要总结论文中的英文单词与短语。你会获得已经标记出来需要总结的论文带标注的pdf，需要你把我标出来的单词按照我的要求总结到scv表格中，并放在指定位置。要求如下：
1.论文中需要总结的部分是用zetero标注的，有其余的不同颜色的标注，我都不需要，你仅查找并总结“使用灰色“、”下划线标注”的。灰色下划线在 PDF 里记录为 /Underline，颜色是 [0.66666667, 0.66666667, 0.66666667]，PDF 里灰色下划线标注很多是单词，但也混有少量术语短语和整句标注，这种术语短语和整句标注部分也需要总结，不需要标注词性和音标，但需要翻译。仅总结标记的字符、单词、短语：过去式的“ed”或者单词后缀如果没有标注，即使前面单词标注了，后缀也应该舍弃；前面标注了短语，后面没标注的部分也应舍弃总结。
2.读取论文名，并且把表格命名为与论文名同名的.csv
3.根据我标记的论文单词生成词汇总结表，表格采用 A-F 六列结构：A列为“单词”，B列为“释义”，C列为“音标”，D列为“论文内例句”，E列为“页码”，F列为“次数”。
4.词汇总结表第1行写论文标题，合并 A1:F1；第2行为表头(短语、释义、音标、例句、页码、次数)；第3行开始填写词汇内容。单词按论文中出现顺序整理，释义使用中文并保留词性，不可省略释义，完全覆盖pdf中标注的释义；音标填写标准音标；论文内例句必须摘自论文原文，不要编造或改写，合理删减，太长的句子就可以不保留整个句子，仅保留短语或者句子一部分，要求是能体现单词的语境结构；页码填写例句所在页；次数展示在论文中标注出来的大于1的次数，仅出现一次则不填写出现次数。
5.输出 CSV，只保留六列内容
